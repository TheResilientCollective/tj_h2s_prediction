# Appendix — how every figure was made

Generated by `run_all.py --manifest`; do not edit by hand.

Every script below is standalone: `python <script>.py` reproduces its
figure and tables from the public URLs in the data-source table, with no
credentials. Intermediate pulls are cached in `data/` (gitignored).

## Scripts

| Output | Script | What it does |
|---|---|---|
| Figure 1 — the complaint record | [`fig01_complaint_record.py`](fig01_complaint_record.py) | what the odour-complaint record actually is. |
| Figure 2 — odour dose-response | [`fig02_dose_response.py`](fig02_dose_response.py) | the odour dose-response: how likely is a complaint at a given H2S? |
| Figure 3 — conditions at complaint time | [`fig03_complaint_conditions.py`](fig03_complaint_conditions.py) | the complainant's-eye view, and a cross-station robustness check. |
| Figure 4 — exceedance record, midnight-centred | [`fig04_exceedance_midnight.py`](fig04_exceedance_midnight.py) | the exceedance record, re-framed on a night that contains midnight. |
| Figure 5 — exceedance clock, midnight-centred | [`fig05_exceedance_clock.py`](fig05_exceedance_clock.py) | "when exceedances happen", re-drawn with midnight in the middle. |
| Figure 6 — seasonality and temperature | [`fig06_seasonality_temperature.py`](fig06_seasonality_temperature.py) | the seasonal cycle, and whether temperature explains it. |
| Table 7 — model feature inventory | [`tbl07_model_features.py`](tbl07_model_features.py) | the features the deployed exceedance-probability models use. |
| Figure 7 — model performance | [`fig07_model_performance.py`](fig07_model_performance.py) | how well the deployed exceedance-probability models actually do. |

## Data sources

All public; no authentication.

| Cached as | URL | What it is |
|---|---|---|
| `modeldata_h2s_nofill.parquet` | https://oss.resilientservice.mooo.com/resilentpublic/latest/tijuana/forecast_data/modeldata_h2s_nofill.parquet | Hourly H2S + meteorology + flow/tide per station. Unmeasured H2S hours are null (no gap fill), which is what makes it safe for exceedance counting. |
| `h2s_locations.csv` | https://oss.resilientservice.mooo.com/resilentpublic/latest/tijuana/forecast_data/h2s_locations.csv | Station coordinates for the San Diego APCD H2S monitors. |
| `forecast_skill_report.json` | https://oss.resilientservice.mooo.com/resilentpublic/latest/tijuana/forecast_data/forecast_skill_report.json | Operational (out-of-sample) skill of the deployed forecast products, rebuilt by station_forecast_validation_rebuild_job. |
| `NESTOR__BES_training_report.json` | https://oss.resilientservice.mooo.com/resilentpublic/tijuana/forecast/models/stations/NESTOR__BES/training_report.json | Held-out training metrics + feature importances for the deployed NESTOR-BES models (both feature variants, all four tasks). |
| `IB_CIVIC_CTR_training_report.json` | https://oss.resilientservice.mooo.com/resilentpublic/tijuana/forecast/models/stations/IB_CIVIC_CTR/training_report.json | Same, IB Civic Center. |
| `SAN_YSIDRO_training_report.json` | https://oss.resilientservice.mooo.com/resilentpublic/tijuana/forecast/models/stations/SAN_YSIDRO/training_report.json | Same, San Ysidro. |
| `NESTOR__BES_deployment_metadata.json` | https://oss.resilientservice.mooo.com/resilentpublic/tijuana/forecast/models/stations/NESTOR__BES/deployment_metadata.json | Deployed model version tag for NESTOR-BES. |
| `IB_CIVIC_CTR_deployment_metadata.json` | https://oss.resilientservice.mooo.com/resilentpublic/tijuana/forecast/models/stations/IB_CIVIC_CTR/deployment_metadata.json | Deployed model version tag for IB Civic Center. |
| `SAN_YSIDRO_deployment_metadata.json` | https://oss.resilientservice.mooo.com/resilentpublic/tijuana/forecast/models/stations/SAN_YSIDRO/deployment_metadata.json | Deployed model version tag for San Ysidro. |
| `validation.parquet` | https://oss.resilientservice.mooo.com/resilentpublic/tijuana/forecast/validation_store/validation.parquet | Every stored forecast product row joined to the H2S actually measured at its target hour — the substrate the skill report is computed from. |
| `complaints_full.json` | https://gis-public.sandiegocounty.gov/arcgis/rest/services/Hosted/SDAPCD_Complaints/FeatureServer/0/query (paged, where=1=1) | Every San Diego APCD complaint record, including date_and_time_received — the real clock time, which the published complaints.csv does not carry. |
